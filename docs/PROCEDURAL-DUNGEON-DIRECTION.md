# Procedural Dungeon Direction

This is the stable front door for the procedural-dungeon redesign discussion. The original monolith
was split on 2026-07-21 into a preserved questionnaire, global foundation, and bounded chronological
wave parts so agents can index and edit only the active material. The split moved historical text
verbatim; it did not consolidate or rewrite prior rulings.

## File-growth rule

Each wave owns a small `README.md` and bounded chronological parts. Append only to the current part.
At a material question boundary near 2,000 lines or 150-200 KB, open the next numbered part and update
both indexes. Bounded projection does not permit deletion: every accepted, rejected, provisional,
parked, and reopened ruling remains in chronological authority.
