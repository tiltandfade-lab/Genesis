
# The Tavern Engine

When the party inevitably wants a drink, roll to generate a tavern fast: **Foundation → Layout → Population → Details**.

> [!tip] Use at table
> Roll **Foundation** first. If you only need a quick scene, stop there.
> If players linger, add **Layout** and **Population**.
> If they start digging, roll **Details**.
