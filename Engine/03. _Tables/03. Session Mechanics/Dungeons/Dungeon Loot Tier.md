# Dungeon Loot — Tier ⚠️ RETIRED 2026-06-18
> **Retired in the loot remap.** This standalone d100 "pick a rarity" table is superseded by the **Budget** system ([[Dungeon Loot Budget T1]] / [[Dungeon Loot Budget T2]] / [[Dungeon Loot Budget T3]] / [[Dungeon Loot Budget T4]]), which assigns item count + rarity by tier and dungeon size. Rarity is no longer rolled flat — it's allocated by depth (boss → rarest).
>
> It also skipped Uncommon and Very Rare entirely (the bug the remap fixed). Original archived as `ARCHIVE Dungeon Loot Tier v1 (pre-remap 2026-06-18)`. Kept as a stub only so old links don't dangle — **do not roll on this.**

See [[Treasure Generator V1.0]] for the current flow and `LOOT-REMAP.md` for the rationale.
