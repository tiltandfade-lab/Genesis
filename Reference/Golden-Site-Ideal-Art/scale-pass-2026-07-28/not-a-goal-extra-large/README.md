# NOT A GOAL — superseded extra-large Golden Site overviews

Status: **archive only — not a gameplay-footprint target**

These nine images are the superseded third-column renders from the first 2026-07-28
scale pass. They are retained only because some contain useful studies of height,
depth, material, silhouette, and site identity.

They must not be used as:

- target BattleMap footprints;
- evidence that a large Golden Site materializes as one continuous board;
- a traversal-time target;
- a request for large empty approaches, districts, campuses, fortresses, or complexes.

The active replacements sit in the normal site folders and are named
`03-large-site-vignette-*`. In the active target set, **large describes the amount of
site identity and relationship represented, not acreage**. A larger Golden Site may
continue through honest frontiers into another compact `MaterializationWindow`.
