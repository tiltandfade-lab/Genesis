## Proposed ladder addition

**F8.1 "the breakable door"** — one retained pass between C1C and C2C: break/burn on one door
and one column through the full spine (action → op → profile → states → connection delta /
support stub → debris → tells → lens → save/remount → honest refusal). One primary risk: the
mutation transaction. C2C remains the multi-room causal gate; C3B the offscreen gate. Ladder
edit applied at Wave 8 closure (2026-07-22, record §17.7).

## Exclusions (owned elsewhere)

Rules content (SRD object rules); connection truth (W4); local prop transactions (W5); crit
authority and reach profiles (W2); card scheduling of prepared reserves (W9); persistence codec
and migration proofs (W12); renderer/feedback presentation (closed W10).

## Ledger reconciliation (proposed)

refines "Touched dressing state" (escalation now lands on a typed registry); adds one row:

fronts + debris + duration classes; proof F8.1/C2C; gate C2C/C3B; goal: full families + realm
material breadth; trigger: corpus/budget evidence). Ledger edits applied at Wave 8 closure
(2026-07-22, record §17.7).
