Here is the stripped-down, free-tier "Starter Scene" checklist, formatted in your exact markup style.

I have removed the premium prep-elimination tools (pre-roll tables, variant tables, item stat blocks, full clue networks, and print PDFs), constrained the scope to a single encounter, and added the vital Call to Action (CTA) block to drive conversions.


#### Header
- Title
- One-line use
- Adventure Promise *(5-10 sec description)*
- Adventure Scale *(Levels 1-5, 6-10, etc..)*
- Tags: Environment, encounter type, tone
- Prep Time
- Pressure Level
- Rewards & Consequences

#### The Set Up
- Basic Narrative
- Why the PCs Care
- Define maps used within the Starter Scene
- Starting NPC *(Limit to 1 main NPC)*
- What happens if the PCs ignore it
	- Alter the economy or social standing (*Change an NPC's attitude to Hostile, increase prices, impose Disadvantage on social checks).*
	- Alter the physical environment *(Destroy a bridge, burn down a tavern, unleash a localized hazard).*
	- Advance the antagonist's timeline *(The villain gets the item, a victim dies, the dungeon becomes heavily fortified).*

#### The Core Segment
*The free tier contains only the opening segment or a single set-piece encounter.*
- DM Read aloud sections - *2-5 sentences max*
- Skill Checks/revelations *(Immediate checks only)*
- PC likely choices
- Instructions to corral players if necessary
- Escalation and pressure keys
- Consequences of escalation and pressure
- Clues & NPCs that can reveal them *(Limit to 1-3 immediate clues)*
- Treasures *(Item names and GP value only; full magic item stats reserved for paid tier)*

#### NPC Dossier (Limit to 1 Key NPC)
- Catchphrase and/or Opening Phrase
- Visual Quirk
- Behavioral Quirk
- Secret
- Goal
- Leverage
- Boundaries
- If Pressed

#### Stat Blocks
- Race, alignment
- Short description
- AC, HP, Speed
- STR, DEX, CON, INT, WIS, CHA
- Saving throws, skills, senses
- Actions
- Tactic

#### Combat Encounters
- CR rating
- XP value

### Bonus Content (Teasers)

#### Maps
- Low-Res or Watermarked Map Image
- 5ft grid
- Event & Item Keys
	- any handles that players may interact with
	- any skill checks & consequences of success/failure
	- general description
- Atmospheric description
- Access points, Entrances/Exits

#### VTT Teaser
- Single screenshot or low-res token teasing the $15+ tier
