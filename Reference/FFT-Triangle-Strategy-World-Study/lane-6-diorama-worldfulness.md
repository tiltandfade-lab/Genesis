# Lane 6 — Diorama edge and worldfulness without acreage

Answers §5.7. This lane holds the study's central question: how a compact board feels like
a world. Frame evidence: FFT five-angle corpus (edges measured), TS frames (canal night,
Wolffort deploy, wheat terraces far-field), IC pairs, Genesis targets + contract docs.

## 6.1 Edge taxonomy (§5.7 Q1)

| treatment | FFT | TS | IC | Genesis today | Genesis ruled target |
|---|---|---|---|---|---|
| hard board edge into void | **default** (black) | never observed | as FFT | neutral gray/void | fallback only (Band 3 grade) |
| composed edge (wall/cliff/water/road-clip) | yes — the discipline | yes (walls, cliffs) | yes | targets: plinth skirt | yes (composed-edge grammar) |
| world continues under haze/blur | no | **yes — signature** | partial (vignette) | no | Bands 1–3 (ruled, unbuilt) |
| display-base plinth | no | no | paper-grain overlay hints at it | **yes (targets literally sit on a base)** | open: plinth vs continuation per venue |

**Arai (primary): the TS team "spent a lot of time discussing what to do at the edge of
maps" at the start of development.** The corpus's biggest presentational divergence —
FFT's void vs TS's continuation — was a deliberate, expensive TS decision, not a free
byproduct of newer hardware.

## 6.2 Foreground / middle / far field (§5.7 Q2)

- FFT: no FG, board-only MG, no FF — 100% of worldfulness carried by composition + the
  player's imagination (and by rotation-as-inspection: Ito's miniature garden).
- TS: thin blurred FG intrusions (rooflines, embers), sharp board MG, real FF (the wheat
  map's hazed golden plain with continuing paths; the canal's blurred city fabric).
- IC: FFT structure + vignette/DoF implying an FG that isn't modeled.
- Genesis: backdrop plate only today; the ruled four-band contract is precisely the TS
  structure with honesty constraints added.

## 6.3 Does background context show real destinations? (§5.7 Q3)

Observed: Wolffort's curtain wall implies the castle/keep beyond — a real story location
reachable in *other windows*; the wheat far-field paths imply plausible but unpromised
world; the canal's blurred fabric is pure premise. **The corpus rule: near context =
real adjacency; far context = premise, never promise.** This is exactly Genesis's ruled
eligibility split (direct visible noun / physical property / premise) — corpus-confirmed.

## 6.4 True vs false affordance (§5.7 Q4)

TS separates playable from scenic by: sharpness (DoF band), value (context darker or
hazed), grid overlay on selection, and elevation discontinuity (context sits beyond a
drop/wall). No case was found of scenic context that reads as a walkable exit — TS's
false-affordance hygiene is real. Genesis's contract adds the stronger guarantee
(routeClaim: none; portal-aligned continuations only) — stricter than the corpus.

## 6.5 How a larger place is implied (§5.7 Q5, Q8)

Corpus methods, ranked by observed frequency: (1) clipped honest continuations (roads/
canals/streets exiting under walls or into haze); (2) vertical envelope above the board
(towers, walls, church spires — scenery masses); (3) far-field premise planes; (4)
weather/atmosphere shared with the implied world; (5) **sibling windows of the same
place** — Wolffort ships as three separate boards of one persistent town (streets, great
hall, tourney court): the linked-window model is *already how the reference game handles
a large site.* Unsafe-for-Genesis: baked crowds/actors in context (seen nowhere in the
corpus either), invented far settlements that contradict rolled adjacency (Genesis's
knowledge-filter already bans).

## 6.6 Height as depth (§5.7 Q7, H4)

Measured/observed: Zirekile (110 cells, 3 bands + void below the bridge) reads deeper
than Mandalia (156 cells, 2 bands); Goug (88 cells!) reads as a whole city via roof
stacking; the wheat terraces get depth from four stacked terrace bands + a cable crossing
*over* them. **Bands and drops buy more perceived depth per cell than any amount of
floor.** Genesis's fortress-vignette target already demonstrates the same effect against
its flat camp sibling. H4 SUPPORTED with frame evidence.

## 6.7 Avoiding empty approach acreage (§5.7 Q9-10)

The corpus never renders travel-to-the-fight: FFT cuts from world map to deployment; TS
walks a *pre-battle exploration phase on the battle board itself* (the town IS the
approach, and it is dense with interlocutors); reinforcements refill crossed ground.
Genesis's movement doctrine + arrival law + linked windows are the same answer stated as
law. The minimum viable embedding (Q9): **one true portal continuation + one support
continuation + a far premise plane + shared atmosphere** — Band 1 + Band 3 with the
graded fallback; Band 2 is enrichment, not the floor.

## 6.8 Six compact-vignette depth recipes (deliverable)

Rendered as original diagrams in `diagrams/compact-depth-recipes.svg`; stated here in the
brief's relational form. All obey: arrival lands ON the first decision (1–3 cells); one
short rising route; one lower/service route; clipped honest continuations; one
scenery-only high mass; near+far context bands; no false exits; no backtrack ground.

1. **R1 Shoulder Overlook** (FFT Grog class): low road arrival → climb-or-pass decision →
   crown deck two bands up → road exits clipped both ends → far ridge premise.
2. **R2 Threshold + Undercroft** (gate/market class): gate mass astride the spine →
   sunken service yard (depth DOWN) → wall-walk above → wall ends clipped honest.
3. **R3 Crossing over a Drop** (Zirekile class): void bisects the board; deck chokepoint;
   risky low ford alternate; the void *continues under* the floor.
4. **R4 Cutaway Stack** (interior/mine class): three floors in one window via camera-side
   omission; stair+ladder verticals; unentered wings stay sealed mass.
5. **R5 Perched Edge** (monastery/lair class): the site sits on a visible support face;
   world continues BELOW the board edge; far premise behind; tower as scenery mass.
6. **R6 Linked Windows** (large-site law): one active compact window + 2–3 precommitted
   frontiers; crossing a frontier materializes the next window — the Wolffort model,
   generalized and made persistent.
