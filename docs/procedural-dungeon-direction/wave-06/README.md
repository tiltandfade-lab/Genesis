# Wave 6 — Creature Scale, Capacity, Squeezing, and Party Participation

Wave 6 is **OPEN** after Wave 5's explicit closure at section 14.9. It inherits canonical identity/aliases,
population/group ownership, true-scale rendering, provenance-first scale domains, structural dimensions, portal/
traversal transactions, furniture/access reservations, exact custody, one advancing pre-alpha party scene, forced-
separation cold records, fixed-camera projection, and provider-neutral DM-seat laws from closed Waves 1-5 and 10.

This wave record is the canonical detailed authority for body/form dimensions, activity-specific capacity,
co-location, squeezing/constrained movement, creature-scale domains, party split/regroup mechanics, CastRoster
aggregation, mounts/vehicles/passengers, transformations, participation roles, scale/access tells, visual scale
projection, and their acceptance evidence. It cannot replace D&D action/effect rules, Wave 2's actor/group/custody
owners, Wave 3's architectural domain provenance, Wave 4's traversal/connection truth, Wave 7's detailed tactical
affordances, Wave 8's broad mutation, or Wave 10's party/projection/performance/accessibility laws.
