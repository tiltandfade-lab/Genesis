# Dungeon Procedure Upgrade Checklist (Obsidian)

> Goal: Single-pass generation with **more secrets + more dressing + more art**
> Constraint: Keep it fast enough to run live.

---

## ✅ Core Rule Changes (Procedure)

- [x] **Make Secrets mandatory:** 1 secret **per segment** (no “presence roll”)
- [ ] Add rule: **Secrets never gate required progression**
- [ ] Add rule: **Every secret has a clue delivery method**
- [ ] Add rule: **At least 1 secret per dungeon is a “route secret”** (shortcut / bypass / flank)

---

## ✅ Add Mandatory “Texture Bundle” Per Segment

Add this block after *Feature / Landmark*:

- [x] **Sensory Line** (1 sentence: smell + sound + light/temperature)
- [x] **Set Dressing Props** (roll 2)
- [x] **Interactable Object** (roll 1; usable as tool/cover/clue/hazard)
- [x] **Art / Marking** (roll 1; mural, carving, sigil, graffiti, mosaic, etc.)

---

## ✅ Add Dungeon-Wide Art Direction (Setup Rolls)

In Dungeon Setup (roll once):

- [x] **Dungeon Motif** (material / symbol / light / sound)  
  - [x] Rule: Motif appears in **3+ segments**
- [x] **Dungeon Palette / Lighting** (normal / dim / none / weird-color)
- [x] **Dungeon “Truth”** (one repeating premise: ward failing / occupied / sealed knowledge leaking)

---

## ✅ Secret System (Per Segment)

Replace current Secret Check with:

- [x] **Secret Type** (roll 1 each segment)
- [x] **Secret Delivery** (roll 1 each segment)
- [x] **Secret Payoff Size** (roll 1 each segment: micro / standard / major)

### Secret Type Table should include:
- [x] Clue (lore, map fragment, overheard plan, evidence)
- [x] Cache (consumables, tools, minor valuables)
- [x] Route (bypass, shortcut, hidden door, alternate entrance)
- [x] Mechanism (lever, valve, rune, movable stone)
- [x] Faction Evidence (who was here, what they want, where they went)
- [x] Weird Phenomenon (arcane glitch, Mere effect, time echo)

### Secret Delivery Table should include:
- [x] Visible but misread
- [x] Skill check to notice (Perception/Investigation)
- [x] Triggered by interaction with dressing
- [x] Requires tool (crowbar, fire, rope, pole)
- [x] Costs time/noise (raises Alert or risks encounter)

### Secret Payoff Size:
- [x] Micro: flavor + minor clue/tool (fast)
- [x] Standard: usable advantage or meaningful info
- [x] Major: route + treasure + revelation (rare)

When Encounter Type = Empty:

- [x] Roll **one**: Micro-Discovery / Clue Fragment / Atmosphere Escalation
- [x] Rule: Empty rooms still include **Texture Bundle + Secret**

## ✅ Expand Rest Pressure Into Playable Prompts

- [ ] Ensure Rest Complications table produces:
  - [ ] a **fictional reason** (noise, cold, dreams, patrols)
  - [ ] a **mechanical nudge** (interruption roll, cost, consequence)

## ✅ Improve Alert System Integration (Light Touch)

- [ ] Add rule: Certain secrets can **raise Alert** if triggered loudly
- [ ] Add rule: Faction encounters can **lower Alert** with deception/bribery/parley
- [ ] Add rule: “Noise cost” is a valid secret delivery method

## ✅ Quality Control Rules (Prevent Bloat)

- [ ] Limit each segment write-up to **3–5 lines**
- [ ] If a secret feels “big,” downgrade it to **micro** unless it’s the finale
- [ ] Prefer **information + routes + tools** over raw gold
- [x] Each segment must include **one thing players can touch/use**
- [x] Every dungeon must include **3 repeating motif appearances**
