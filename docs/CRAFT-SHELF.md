**Conventions binding all kin-tension rows:**

- **Kin-agnostic.** Never hardcode which species: rows say "the NPC's kin" / "the old line" /
  "across the line"; the rolled Race atoms + codex decide which kin, per the same
  recontextualize convention as trade details.
- **Anti-drift.** The DM never invents who-resents-whom mid-turn; the tension reads from rolled
  facts. The fully mechanized home — a world-gen **fault-line roll** per settlement (war
  memory, plague blame, guild exclusion, old dispossession) feeding the attitude/parley
  system — is PARKED as a spec question for Adam. Not queued.
- **Band-honest** per SPICE-CURVE: exclusion and custom are Grounded; return-of-the-suppressed
  is Textured; an organizing force is Volatile; a world-forever reckoning is Mythic.
