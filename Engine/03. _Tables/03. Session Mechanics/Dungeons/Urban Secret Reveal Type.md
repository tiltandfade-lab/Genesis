## Urban Secret Reveal Type (Multi-Skill) — d20
> Roll after Secret Tier. This result tells you the *reveal vector*.
> Then choose **one** of the listed skills (player-led) or offer multiple if they describe a smart approach.

| d20 | Reveal Vector | Skills that can discover it (pick based on approach) |
|---:|--------------|--------------------------------------------------------|
| 1  | **Visual Anomaly** | Perception / Investigation / Arcana (if magical residue) |
| 2  | **Spatial Inconsistency** | Investigation / Perception / Survival (tracking routes, gaps, or flow) |
| 3  | **Wear & Traffic Pattern** | Perception / Investigation / Survival (tracks, scuffs, repeated use) |
| 4  | **Hidden Mechanism** | Investigation / Sleight of Hand / Thieves’ Tools (if appropriate) |
| 5  | **Acoustic Tell (Hollow / Draft)** | Perception / Investigation / Nature (airflow/echo logic) |
| 6  | **Scent / Air Chemistry Cue** | Perception / Nature / Medicine (rot, smoke, ozone, sewage, incense) |
| 7  | **Material Discontinuity** | Investigation / Arcana / History (new mortar, wrong wood, replaced stone, old craft) |
| 8  | **Symbol / Text / Diagram** | Investigation / History / Religion / Arcana (context decides) |
| 9  | **Ritual Logic / Sacred Pattern** | Religion / Arcana / History (meaning, placement, taboo) |
| 10 | **Arcane Residue / Ward Pattern** | Arcana / Investigation / Perception (seeing the “wrongness”) |
| 11 | **Creature Sign / Urban Ecology** | Nature / Survival / Perception (nests, vermin trails, animal behavior) |
| 12 | **Water / Drainage Logic** | Investigation / Survival / Nature (runoff, pooling, seepage, drains) |
| 13 | **Engineering / Load-Bearing Weirdness** | Investigation / Perception / Athletics (stress test, leverage, support logic) |
| 14 | **Trap Adjacent / Tamper Evidence** | Investigation / Perception / Thieves’ Tools / Sleight of Hand |
| 15 | **Heat / Cold / Condensation Pattern** | Perception / Investigation / Arcana (if supernatural) |
| 16 | **Light & Shadow Misbehavior** | Perception / Investigation / Arcana (illumination reveals seam or route) |
| 17 | **Social Leakage (someone knows)** | Insight / Persuasion / Intimidation / Deception |
| 18 | **Language / Code / Cipher** | Investigation / History / Arcana (or Thieves’ Cant-style logic) |
| 19 | **Psychic / Dream / Memory Echo** | Wisdom (Perception) / Insight / Arcana (interpret the echo) |
| 20 | **Pressure Event Reveal** | Any: triggered during conflict, hazard, or pursuit—then a check determines *how much* they glean (Perception/Investigation/Arcana/etc.) |
^urban-secret-reveal-type
