# Misidentified Villain

Type: Narrative Device  
Purpose: Redirect suspicion to create investigative tension and moral complexity.

## Core Concept
The apparent antagonist is not the true source of harm.

## Typical Uses
- Framed NPC
- Misleading evidence
- Emotional bias
- Convenient scapegoat
- Incomplete information

## Attach To
- Public scandals
- Murders
- Kidnappings
- Political unrest
- Theft

## Sources of Misidentification
- Forged evidence
- Witness error
- Planted item
- Shared symbol
- Look-alike
- Old grudge

## Revelation Paths
- Contradictory timeline
- Overlooked physical detail
- Inconsistent testimony
- Discovery of manipulation
- Hidden patron uncovered

## Escalation Options
- Party publicly accuses wrong target.
- Innocent party retaliates.
- True villain manipulates investigation.
- Town descends into paranoia.

> Design Note:
> Misidentified Villain increases tension only if the false target is plausible.
> Avoid obvious twists.
