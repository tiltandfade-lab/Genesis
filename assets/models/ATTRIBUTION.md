# assets/models/ — attribution & license capture

Landed under `chore/model-packs` (2026-07-03) per docs/BATTLE-THEATER.md §3 (T2 pack-download
pre-step). All packs below are **CC0** (Creative Commons Zero / public domain dedication) —
verified both from the source page and from the `License.txt` shipped inside each pack's zip.
No attribution is legally required; credit given here anyway as good practice.

Format kept: `.glb` only (self-contained binary glTF — geometry + materials + textures in one
file). Source zips also included `FBX/`, `OBJ/`, and loose `Textures/` — those were **not**
copied in; no `.blend` source files or promo images were copied in either.

## Skipped sources (documented, not fabricated)

### Quaternius (quaternius.com) — SKIPPED, all three target packs

Tried in priority order per the task brief: **Ultimate Monsters**, **RPG Characters**,
**Ultimate RPG**. All three are CC0 (confirmed on-page: quaternius.com license badge links
`creativecommons.org/publicdomain/zero/1.0/`), but every download button on quaternius.com
resolves to a **Google Drive folder interstitial** (interactive, requires a browser to
navigate/select-download, not a static fetchable URL):

- Ultimate Monsters → `https://drive.google.com/drive/folders/18m4KpzpEzhC9wl7jzr6dUc0N8Jozr79C`
- RPG Characters → `https://drive.google.com/drive/folders/1MIRQXLfTd21HMI5rwOb6Xy0rv0xv1m8b`
- Ultimate RPG → `https://drive.google.com/drive/folders/1IhdL3W5XdJrjf_axqAnKvEybMaC3FwF-`

Per the task's explicit rule ("if a pack's URL only resolves through an interactive page …
SKIP that pack and note it — do not flail"), these were not pursued further.

**Secondary path checked:** quaternius.com also links an itch.io storefront
(`quaternius.itch.io`), which mirrors many of the same packs (e.g.
`lowpoly-animated-monsters`, `fantasy-props-megakit`, `lowpoly-modular-dungeon-pack`) as
free/"name your own price" CC0 downloads. Investigated whether these resolve to a stable
direct-download URL: itch.io's download flow is a signed, short-lived, session-scoped token
issued via a POST to `<game>/download_url` (requires a CSRF token pulled from the HTML page),
which in turn returns a page whose actual file link is behind a JS `onclick` handler bound to
`data-upload_id` — there is no static file URL, only a client-side download flow itch.io
intends for browser use. This was confirmed live (the POST succeeded and returned a signed
`/download/<token>` URL, but that URL serves another HTML shell, not the zip bytes). Treated as
equivalently interactive-only and skipped, consistent with the Google Drive call — not pursued
further to avoid reverse-engineering a vendor's session/auth flow.

**Net result:** zero Quaternius files landed. If Adam wants these specifically, the fastest
path is a manual browser download (Google Drive folder → Download, or itch.io → Download Now)
dropped into `assets/models/quaternius-<pack-slug>/` with this same attribution treatment.

### Kenney packs considered but not pursued

Only the three packs above were pulled — they were sufficient to cover the "creature figures +
a dozen-plus props" bar inside the size budget. Other Kenney fantasy-tagged packs seen on the
`kenney.nl/assets?q=fantasy` listing (Pirate Kit, Retro Textures Fantasy, and others further
down the 13-page tag listing) were not investigated; nothing was attempted-and-failed for
Kenney, they were simply out of scope once the budget/coverage bar was met.
