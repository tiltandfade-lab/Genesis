| d20 | Secret Tier | Result                                                                                                                   |
| --: | :---------: | ------------------------------------------------------------------------------------------------------------------------ |
|   1 |    Micro    | **Loose stone / floorboard stash.** Trifle + clue fragment (scrap, token, wax seal, chalk mark).                         |
|   2 |    Micro    | **Hairline seam.** A panel is *almost* hidden; opening it is trivial but requires noticing.                              |
|   3 |    Micro    | **Misleading architectural asymmetry.** False doorframe / uneven arch / misaligned tiles (points to a deeper secret).    |
|   4 |    Micro    | **Hidden message in plain sight.** Scrawled warning, prayer, tally, children’s marks, symbol drift clue.                 |
|   5 |    Micro    | **Dropped evidence.** Footprints + a small object (button, scrap of cloth, arrow fletching, ritual bead).                |
|   6 |    Micro    | **Tiny cache.** 1–2 consumables or mundane resources (oil, chalk, bandage kit, rations, pitons).                         |
|   7 |    Minor    | **Hollow feature compartment.** Inside statue, pillar, brazier base, cracked urn (requires interaction).                 |
|   8 |    Minor    | **Pocket behind environment feature.** Behind tapestry, under basin lip, inside fireplace throat.                        |
|   9 |    Minor    | **Environmental trigger reveal.** Drain/fill water, rotate carving, move rubble → compartment opens.                     |
|  10 |    Minor    | **Secret bypass (small).** Maintenance slit / crawlspace / arrow-loop passage (skip hazard or gain flank).               |
|  11 |    Minor    | **Hidden tool advantage.** A useful item staged here (rope ladder, prybar, spare lantern, wedge spikes).                 |
|  12 |  Standard   | **Hidden compartment with meaning.** Clue + usable reward (map scrap, key, antitoxin, scroll, etc.).                     |
|  13 |  Standard   | **Concealed utility room.** Store, guard nook, ritual prep room, office—contains info + something practical.             |
|  14 |  Standard   | **Concealed route room.** Optional alternate entrance/exit point *within* the dungeon (never the only way).              |
|  15 |  Standard   | **Secret encounter space.** Prisoner, spy, scavenger, lone monster, or sentry posted in a hidden nook.                   |
|  16 |  Standard   | **Faction evidence cache.** Ledger, contraband, coded letter, uniforms, offerings (points to outside pressure).          |
|  17 |    Major    | **Major secret chamber tied to dungeon origin.** Founding mark, ward node, relic niche, iconic mural/inscription.        |
|  18 |    Major    | **The dungeon lies.** A room is a façade (fake shrine/treasury) hiding the true function behind/under it.                |
|  19 |    Major    | **Major route revelation.** Shortcut to approach/finale region, escape tunnel, hidden stair to another depth (optional). |
|  20 |   Mythic    | **Signature secret.** Unique revelation + reward that becomes campaign glue (named relic, key truth, recurring motif).   |
