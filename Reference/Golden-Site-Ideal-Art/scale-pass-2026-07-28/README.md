# Golden Site scale targets — 2026-07-28

Status: **visual direction / build target — not runtime proof**

This pass contains 27 active generated map targets: small, medium, and a compact
large-site vignette for nine Golden Site families.

- Previously unrendered: Site 3 Dormant, Site 8 Layered Control, Site 9 Contested
  Fortress, Site 11 Mixed Scale, and Site 12 Substrate.
- Materially changed since the prior render commit: Site 2 Camp / Service, Site 4
  Monastery / Commune, Site 5 Mine / Workshop, and Site 10 Urban Institution.
- Retained without rerender: Site 6 Prison / Custody. Its newer changes are research and
  doctrine additions rather than a materially different ruled visual chassis.

The user-supplied current terrain-engine frame is preserved at
`source-references/current-terrain-engine-two-tray-reference.png`. It is the primary
terrain-language reference for this pass: continuous folded cell-spanning landforms,
embedded route cuts, sparse causal breaks, and readable character-to-cell scale.

Generation used the built-in image-generation mode, one call per candidate. The
original small and medium images combined the current terrain reference, one approved
Genesis ideal-art host/style reference, and one plan or real-world study image where
available. The replacement third-column pass used the current terrain reference and
real images from this target set, preserving site identity while explicitly discarding
overview acreage. Exact shared constraints, scene briefs, rolls, and references are recorded in
[PROMPT-SET.md](PROMPT-SET.md).

## Active-window scale ruling

The former extra-large overview boards are **not a goal**. They have been moved out of
the active site folders into the
[clearly marked archive](not-a-goal-extra-large/README.md). They remain useful only as
height, depth, silhouette, material, and site-identity studies.

The active third column now means **large-site vignette**, not large map:

- one compact `MaterializationWindow`;
- arrival at or very near the first decision;
- height concentrated in stacked bands, cutaways, overlooks, and short vertical routes;
- the larger site implied through a few honest, precommitted frontiers;
- another compact window may materialize when play actually crosses one of those
  frontiers.

Large is semantic breadth, persistence, and linked-site identity—not acreage or walking
time.
