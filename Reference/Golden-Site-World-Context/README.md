# Golden Site real-roll world-context evidence

Status: **implementation evidence — not runtime context proof**

This packet supports
[`docs/GOLDEN-SITE-WORLD-CONTEXT-PROJECTION.md`](../../docs/GOLDEN-SITE-WORLD-CONTEXT-PROJECTION.md).
It records six complete current world-genesis replay-harness draws plus the existing
Prison / Custody reconstruction receipt.

The six world draws execute the live `STAGES` order and `lookup()` tables. A recorded
Mulberry32 harness replaces the live unseeded `Math.random` only so the audit can be
replayed. These are real current roll results, but the harness seeds are not product
world seeds and must never be presented as such.

The packet exists to prevent future background art from starting with generic biome
mood. Each study begins with the actual collision of setting, construction, sensory
facts, nearby places, myth, faction, pressure, and a Golden Site family.

Not every rolled fact becomes visible. The projection spec distinguishes direct visual
nouns and physical properties from sensory, social, secret, and latent facts.

the renderer can compose them. They deliberately reserve a quiet lower apron for tray
overlap and concentrate rolled context in broad middle- and far-field mass. Their
lighting, crop, depth, compatibility metadata, layer separation, and renderer behavior
still require production authoring and runtime proof.

The Canal-Knot target also records an instructive rejection. Its first draft presented
many room-like blocks and crossing choices and therefore read as a second tactical map.
The retained revision collapses those choices into broad district mass. Rich context
does not receive topology authority.
