# Genesis Dev Portal mock set

`portal-mock-01-a.png` through `portal-mock-10-a.png` are the initial tool-suite concepts.
`portal-mock-04-b.png` replaces the animation-oriented Sprite Editor with discrete boss/PC emotes;
`portal-mock-04-c.png` adds the auditable sprite-retirement workflow.

`portal-mock-01-d.png` is the governing home-screen concept. It supersedes the viewport-heavy
`01-a`/`01-b`/`01-c` launcher drafts with a dedicated 4×3 chooser and no engine preview. The matching
12-icon sprite sheet is `portal-dev-icons-c.png`.

Additional portal pages:

- `portal-mock-11-a.png` — Bestiary.
- `portal-mock-12-a.png` — Table Atlas.
- `portal-mock-13-a.png` — Wiki.
- `portal-mock-14-a.png` — Warp & Motion Workshop.

## Reusable icon sprite sheet

- `portal-dev-icons-c.png` — the current twelve-tool icon family on a normalized flat `#FF00FF`
  chroma key, in the exact registry order documented by `docs/DEV-PORTAL.md`. It supersedes the
  earlier eight-icon `portal-dev-icons-b.png` draft.
