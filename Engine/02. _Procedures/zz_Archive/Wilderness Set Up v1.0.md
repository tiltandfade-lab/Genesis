## A. Alert Level (Living Environment)

| Alert Level | State        | Wilderness Behavior |
|-------------|-------------|---------------------|
| 0           | Unaware     | Normal activity. No adjustments. |
| 1           | Suspicious  | Predators/scouts become cautious. Signs of pursuit appear. |
| 2           | Searching   | +1 creature added to future combat encounters (within reason). Threats reposition or stalk. |
| 3           | Mobilized   | Major threat adapts route, sets ambush, or calls reinforcements. Reinforcement roll allowed. |

---

### Alert Increases When:

| Trigger Event |
|---------------|
| Combat lasts 3+ rounds |
| Loud magic used (thunder, explosions, collapse) |
| Enemy escapes |
| Clear tracks/signature left behind |
| Distortion event alters terrain |

If one or more occur → Increase Alert by 1 (max 3)
