# Genesis FFT Guard Post Study

Created 2026-07-23 as an external, Desktop-local research workspace for the procedural Guard Post
and the wider twelve-golden-site structure/material catalog.

This folder is deliberately outside the Genesis repository and its Git worktrees.

## Purpose

Study the compositional grammar of Final Fantasy Tactics battle maps—especially elevation masses,
roads, terrain/building interlock, rocks, vegetation, negative space, tactical routes, composed
edges, and fixed-camera readability—without copying FFT layouts or using FFT art in Genesis.

The output of the study should be:

- table-authored composition archetypes and meaningful alternatives;
- typed relational grammar, constraints, anti-rules, and fallback order;
- deterministic engine-roller requirements;
- procedural structure and material kit requirements;
- retained hero, changed-seed, rejected, and adversarial evidence.

## Legal and production boundary

- Public screenshots and community documentation are reference evidence only.
- Open-source tools remain under their own licenses.
- No FFT mesh, texture, map, or other copyrighted game asset may become a Genesis production asset.
- No unauthorized FFT ISO or raw game-data redistribution belongs here.
- If raw map inspection becomes necessary, Adam must supply his own lawful PSX disc dump privately.
- A private disc image must never be committed to Genesis or redistributed.

## Layout

- `downloads/` — original public archives, retained unchanged.
- `maps/five-angle/` — extracted five-angle reference corpus.
- `maps/existing-screenshots/` — copy of the 22 loose reference images that were already in the
  Genesis root, preserved here against the planned repository move.
- `tools/` — public open-source inspection and extraction tools.
- `reference-index/` — public map indexes and metadata used to select study cohorts.
- `historical-reference/` — culturally separated photos, plans, reconstructions, source/license
  ledger, contact sheets, and a plain-language visual decision guide for the Guard Post.
- `analysis/` — Genesis-authored measurements, contact sheets, annotations, rules, and findings.
