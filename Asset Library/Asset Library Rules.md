# ASSET_LIBRARY – Rules & Philosophy

Purpose:  
Reusable, neutral building blocks for world construction.

This folder contains:
- NPC templates (Role_Hook format)
- Location templates
- Quest modules
- Narrative_Devices
- Reusable structural patterns

---

## Core Principles

- Assets are neutral.
- Assets contain no canon history.
- Assets contain no fixed timeline outcomes.
- Assets use Role_Hook naming.
- Assets never use plain personal names.
- Assets are reusable across worlds.

---

## Promotion Rule

the Vale Event  
→ Extract structural pattern  
→ Strip identity  
→ Refine into Asset  

Never copy world-state directly into Assets.

---

## What Does NOT Belong Here

- Canon events
- Miracle history
- Named Firmament NPCs
- Playtest session logs
- Timeline-specific consequences

---

## Mental Model

Assets are Lego bricks.

They are not scenes.
They are not history.
They are components.
