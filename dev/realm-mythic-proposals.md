# Realm Mythic Row → Gateway-Pool Proposals

**Status: PROPOSAL DIFFS ONLY. No table has been edited. Adam approves row-by-row.**

Addresses the `dev/top-band-uniqueness-report.md` Realm Items finding (rows 28–38, class-(iii)
bare-unique-noun): every realm's single Mythic row (row 27) is a fixed, named, one-of-a-kind
relic that reads byte-identically if two worlds both roll that realm's breach.

**The fix pattern (Adam-approved on the Gloom exemplar):** the bare-unique Mythic row becomes a
GATEWAY into a `d4` pool of TEMPLATE-IZED variants. The pool picks WHAT KIND of relic; the
[bracketed] binding slots localize WHOSE it is against data the world actually rolls. Variant 1 in
every pool = **the current row, slotted, with its R1/R2 effect tiers unchanged.** Variants 2–4 are
new, each with its own R1(L9)/R2(L12) tiers in the table's existing effect-column format.

Each variant is written to match THAT realm's author-voice (its J3b register line, quoted per
realm). Each is a promise-with-a-hook — something a community organized itself around, something
that knows or wants or waits — not an object description. Slot dictionary at the end.

Register reminder: reality-breaking rungs floor at L9 (R1 = L9, R2 = L12), per every realm's
frontmatter. Frame stays as the current row's frame unless noted. Slots use `[brackets]`.

### Slot-usage summary (for the row-by-row review)

- **Clean-binding slots** used freely: `[this settlement]`, `[the region]`, `[the local
  name-culture]`, `[a name from the local name-culture]`. Every realm's variants lean primarily on
  these.
- **Flagged slots** (DM-fill, no clean engine hand-off): `[the region's fallen power]` (used in Ash
  #4, Cosmic #4, Frontier #3, High-Seas #2, Lost-World #2, Noir #2, Theater #3) and `[the region's
  calamity]` (Gloom #2 only). Both are supported by existing region/place/myth lore for a DM to
  fill, but neither is a discrete field the engine emits today. If Adam wants these hard-bound
  rather than DM-filled, the cheapest fix is to add a "fallen power" line to Region Identity's
  write-once roll (it already writes a codex `region` record) — flagged for his call, not assumed.
- **Frames:** every variant inherits its current row's frame (`robe`, except Frontier `pistol`),
  with two deliberate exceptions noted inline where the object is a firearm (Frontier keeps `pistol`;
  Noir #3's service revolver proposes `pistol`). All other proposed variants stay `robe`, matching
  their current Mythic row's frame — no new frames invented (frameless would be a spec bug per the
  realm frontmatter).
