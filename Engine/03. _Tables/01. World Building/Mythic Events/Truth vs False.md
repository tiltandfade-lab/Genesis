### Myth Truth Status (roll secretly)
> **PROVISIONAL — Adam spot-check pending.** Expanded from d6 to d20 (`BATCH2-GUARDRAILS.md` H2,
> wave-2b maintenance). The original 6 rows are byte-untouched (now at 1, 4, 8, 12, 16, 20); the
> new rows interpolate finer gradations along the same truth-gradient, so a d20 roll doesn't
> jump between extremes as coarsely as the old d6 did.

|  d20 | Status                         |
| --: | ------------------------------ |
|   1 | Entirely false                 |
|   2 | Fabricated whole-cloth, but built from a real fear the tellers actually share |
|   3 | Someone invented it to explain a coincidence, and the invention outlived the coincidence |
|   4 | Mostly false, emotionally true |
|   5 | The event happened; every named participant is wrong |
|   6 | The core claim is false; a smaller, stranger true thing sits underneath it, unnoticed |
|   7 | Half-remembered from something that happened to someone else entirely |
|   8 | Misattributed cause            |
|   9 | The effect is real; the myth's explanation for it is a later, tidier lie |
|  10 | True in outline, false in every specific someone could actually check |
|  11 | The myth compresses three separate events into one, and gets the order wrong |
|  12 | Accurate, wrong explanation    |
|  13 | The facts are right; the myth's moral is a later addition that doesn't fit them |
|  14 | True, but the myth omits the one detail that would make it far worse |
|  15 | Mostly true, details wrong     |
|  16 | Uncomfortably accurate         |
|  17 | Accurate, and the myth is quietly softer than what actually happened |
|  18 | True in every particular, and still being carried out by someone who thinks it ended |
|  19 | True, and the teller knows it, and is testing whether the listener already knows too |
|  20 | Exact. The myth is not describing the past — it is still, right now, describing something that hasn't finished happening |
