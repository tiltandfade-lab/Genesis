# REALM-ROLE-EDGES — the add-only roles per realm

The realm-unique roles that exist ONLY in each realm (approach C adds), grounded in each realm's
`data/realms.js` register (quoted). ~10 per realm — enough cast for a living place. These layer
on top of the reskinned universal spine ([[NPC-ROLE-REALMS]]); reskin label-maps + drops come next.
