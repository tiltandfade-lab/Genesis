# Starting State — Opening Bundle

The Entry bridge assembles each opening slot by preference order — **PC backstory seeds → factions → pressures → fresh roll**. These tables are the *fresh roll*: the script's guarantee that no slot is ever empty, so the opening is fully realized even for a blank-slate character in a thin world (the anti-drift posture — the script serves the state, the AI only interprets it).

Slots follow the Dungeon-World opening convention: **Enemies · Friends · Complications · Things · Places.**

**Spice (per [[SPICE-CURVE]]):** these are **Commitment**-class tables — the class permitted to roll Volatile/Mythic. Distribution is honest static rarity: `1–66 Grounded · 67–86 Textured · 87–95 Strange · 96–99 Volatile · 100 Mythic`. The curveballs (a bound fiend, a revenant, a rift, a shard fallen from the sky, a small local god, a world-rewriting artifact) are real but rare — the dice decide, never a dial. Band drives player-facing **juice**; the row content stays the DM's to reveal.
