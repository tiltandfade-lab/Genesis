# Name Cultures — the 12 regional name-banks (`REGIONS-NAMES.md` §3/§5)
> **PROVISIONAL — Adam spot-check pending.** Original phonology-inspired coinages per
> culture-timbre (world-agnostic; no real-world name lists verbatim), anchored to the 12
> approved culture briefs (`REGIONS-NAMES.md` §5) — each culture's approved sample name is
> included verbatim as entry 01 in its bank. `type: name-bank` — the dice compiler skips
> this file (same convention as `NPC Name Megatable.md`); `build/gen-names.py --cultures`
> parses the packed 2-column tables below into `data/names-cultures.js`. Each region's
> identity roll assigns 2 of these 12 cultures; an in-region NPC mint draws region culture
> (70%) × species flavor (30%) — the species megatable stays for nonhuman timbre, blended
> not replaced.
