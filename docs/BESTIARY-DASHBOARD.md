# BESTIARY DASHBOARD — the Monster Manual as a standing QA/coverage instrument

Source idea: `GPT-5.5-advice-for-Claude/README.md` §"Bestiary Manual Read" (lines 246–265).
The Monster Manual (docs/BESTIARY-MANUAL.md, built as Reference Shelf app #1) is already a
reference app; this unit upgrades it into the **standing coverage dashboard** for the whole
creature/model system: model-tier coverage counts up front, QA-gap filters, a per-creature
"edit target" copy bundle that routes Adam's dictated edits to the correct SOURCE (never the
generated artifact), and a loud realm-provenance callout that de-mines the chassis-vs-skin
conflation trap for every future agent.

**The manual stays READ-ONLY.** No inline editing, no write-back, in any form, until the
source-ownership path is airtight (GPT's own caution; also BESTIARY-MANUAL.md "Non-goals").
The edit-target bundle is *text about where to edit*, never an edit affordance.

Everything here is deterministic script work over already-loaded globals. Zero model calls,
zero new network requests, zero effect on any per-turn hot path (the Shelf never runs during
play — REFERENCE-SHELF.md access model).

## 2. Surface 1 — the coverage header strip

### 2.1 Data: `coverageCounts(entries)` (new pure export in ref-bestiary.js)

```js
// Pure — operates ONLY on the caller-supplied entries array (never touches _cachedEntries,
// never reads window inside the loop). All predicates below are the single source of truth
// for both the strip and the filters (§3) — implement ONCE, reuse.
export function coverageCounts(entries) {
  // returns exactly:
  // {
  //   total, regular, realm,
  //   tiers:        { registered, recipe, cuboid },          // whole roster
  //   tiersRegular: { registered, recipe, cuboid },
  //   tiersRealm:   { registered, recipe, cuboid },
  //   needsDesc, needsFlavor, frameMissing, frameMismatch
  // }
}
```

Predicates (exact, shared with §3):

```js
function needsDesc(e)   { return !(e.desc && String(e.desc).trim()); }
function needsFlavor(e) { return !(e.flavorTable && Array.isArray(e.flavorTable.rows)
                                   && e.flavorTable.rows.length >= 8); } // a partial d8 is a gap
function crKey(v) {
  if (v == null || v === "") return null;
  const s = String(v);
  if (s.includes("/")) { const [a, b] = s.split("/"); const f = Number(a) / Number(b);
                         return Number.isFinite(f) ? f : null; }   // robustness only — no "1/8" today
  const n = Number(s);
  return Number.isFinite(n) ? n : null;
}
function frameState(e) { // realm corpus only; regular returns "n/a"
  if (e.corpus !== "realm") return "n/a";
  if (!e.frameResolved) return "missing";
  if (crKey(e.cr) !== crKey(e.frameCr)) return "mismatch"; // null===null → falls through to ok
  return "ok";
}
```

Adapter additions (in `_realmEntries`, ref-bestiary.js:79 — the `frame` chassis lookup already
happens there at line 90): each realm entry gains `frameResolved: !!frame`,
`frameCr: frame ? frame.cr : null`, `frameSrc: frame ? (frame.src || null) : null`,
`rowIndex: <index within realmBestiary[realm]>`, `rowSource: e.source || null`,
`rowSourceNote: e.sourceNote || null`. Each regular entry (in `_regularEntries`, :44) gains
`src: b.src || null` (populated after §5 lands; `null`-tolerant before). Tier resolution reuses
the existing `provenanceTierFor` (ref-bestiary.js:145) verbatim — do NOT re-derive precedence.

### 3.2 Predicate wiring (site: `_applyFilters()`, ref-bestiary.js:647)

Before (lines 656-657):
```js
    if (filters.hasFlavor === "1" && !(e.flavorTable && e.flavorTable.rows && e.flavorTable.rows.length)) return false;
    if (filters.hasDesc === "1" && !e.desc) return false;
```

### 3.4 Edge cases (ruled)

| case | ruling |
|---|---|
| entry `desc` is whitespace-only | `needsDesc` → true (`.trim()` in the predicate) |
| flavorTable present, `rows.length === 7` | `needsFlavor` → true (strict d8 rule) |
| realm row cr `0.5` vs frame cr `1.0` (number vs number) | `crKey` compares numerically → mismatch |
| both cr values null/absent | `null === null` → NOT a mismatch → `ok` (frame resolved) |
| a future regen emits cr as `"1/8"` string | `crKey` fraction branch handles it — no crash, correct compare |
| filter `frame=missing` today | 0 rows (correct — tripwire filter; count proves the pipe, §7.4 proves the trigger) |
| `mm_hasDesc=1&mm_desc=needs` in one URL | new key wins (`needs`) |
| unknown `mm_frame=weird` value | no entry matches (`frameState` never returns "weird") — empty grid, no crash |
