## The assignment in one line

supply, and translate that into how Genesis gets Triangle-Strategy-grade world beauty inside
FFT-sized consequential vignettes — while staying a persistent, roll-authored, state-mutable
solo project.

## Headline measurement (the number that anchors everything)

All 117 clean battle-flagged FFT maps measured exactly (28 px/tile top-down renders):
**median 120 cells · maximum 225 cells (15×15) · longest side never exceeds 18.** Genesis's
current prompt ceiling (16×18 = 288) exceeds every map FFT ever shipped; the tightened
10×14 refinement matches FFT's median almost exactly.
