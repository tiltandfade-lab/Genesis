# Wave A1 — Ready-to-Copy Prompts

Each section is a single complete prompt: copy one whole block into Terra. It contains the image brief, exact save path, and the Meshy operation to return alongside the finished image. No bracket fields or second lookup.

The chunky FFT-like direction means a modern, practical low-poly isometric-tactics prop with few large readable forms. It does not mean copying an existing Final Fantasy Tactics asset.
