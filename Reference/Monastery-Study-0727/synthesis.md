## 2. THE DECISION-READY M1/M2/M4/M5 PACKET

Four founder questions, in the format the concepting guidelines ask for (plain-English
description · alternatives · recommendation and reason · what it changes later · revisibility ·
proof needed). Each restates the existing catalog recommendation (`GOLDEN-SITES-CATALOG.md`
Site 4, "the monastery packet — first rulings + the variant build order") and states plainly
whether this pass's new evidence reinforces, complicates, or leaves it unchanged. **None of the
four recommendations changed as a result of this pass** — the new evidence reinforces three of
them and adds one honest complication to the fourth. That itself is useful information: the
original recommendation was already well-argued, and four independent new cultural sources did
not surface a reason to revise it.

### M1 — Build order for the court family: B (level yard) → C (stacked courts) → A (terrace-face arcade)

**The choice.** Which composition gets built first: a single level court wrapped by arcade
(**B**), two level courts at different heights joined by a stair (**C**), or the arcade read
from below on a retaining terrace face (**A**)?

**Recommendation (unchanged): B, then C, then A.** B proves the reusable arcade-bay technology
at the lowest cost; C repeats that technology (two B-courts stacked); A promotes the proven bay
onto the hardest camera/support problem last.

**What this pass adds.** Two independent, reinforcing signals:

- `FFT-COHORT-COMPARISON.md` §1 (M4-FFT-3) confirms, from two newly-sampled angles on FFT's own
  Orbonne Monastery, that **no arcade geometry appears on the climb itself** — the terrace-face
  arcade (variant A) has no precedent even in the game's own reference cohort, everywhere else in
  either FFT lane. Building it last, after the simpler forms are proven, is the lower-risk order.
- None of this pass's four new monastic cultures (Coptic, Ethiopian, Zen, Sufi khanqah) use a
  stacked or terraced multi-court form. The khanqah is one court; the Coptic compound is one
  walled enclosure around several buildings; the Zen *shichidō garan* is not a wrapped-court
  chassis at all (seven separate halls — a genuinely different institutional grammar, noted but
  not folded into this recommendation, see §3 below); Debre Damo is a small cliff-top cluster.
  Four more independent traditions, and none of them argue FOR building the two-court or
  terrace-face forms first.

**What this changes later.** Nothing new — the ladder links already recorded (C degrades to B by
deleting a court; A is B's arcade promoted onto a face) stand.

**Revisibility.** Easy. This is a build-order choice among three variants that ALL remain
canon (the generator principle) — reordering later costs nothing but resequencing work already
scoped.

**Proof needed.** The Golden Seed clay pass itself: one live Rung-B court through the fixed
production camera, per the working spec's "First visual proof" section — unchanged by this pass.

### M2 — Gate placement: centered first, corner-offset later

**The choice.** Does the ceremonial gate sit centered on the low wall (on the processional axis),
or offset to a corner (an oblique, tactically richer entry)?

**Recommendation (unchanged): centered first.** The evidenced processional axis organizes gate,
stair, and chapel on one line for free; the corner gate is a later placement roll on the same
wall run once validation handles gate-position freedom.

**What this pass adds.** One new, independent, reinforcing signal: Hancock Shaker Village's Brick
Dwelling (`LICENSE-LEDGER.md` M4-05) shows a **single centered entrance approached by a straight
lawn path**, in a building tradition with no liturgical or processional obligation whatsoever —
the Shakers had no reason to inherit a church's axial-gate convention, and built one anyway. This
is weak-but-real evidence that a centered principal entrance is not merely a Christian
processional habit; it recurs in an unrelated communal building tradition, which mildly
strengthens "centered first" as the lower-risk default to build.

**What this changes later.** Nothing new.

**Revisibility.** Easy — a corner-gate placement roll on the same wall run, as already recorded.

**Proof needed.** Unchanged — the working spec's Golden Seed proof.

### M4 — Court count: one yard first, outer/inner filter arrives with M1-C

**The choice.** Does the seed have one yard, or an outer (guest/service) court and an inner
(cloister) court with a filter threshold between them?

**Recommendation (unchanged): one yard first.** The two-court filter arrives together with M1's
stacked-court (C) build, as the same construction — the filter threshold is a social-boundary
piece Sites 6 and 8 also reuse, so it is not lost by deferring it, only sequenced after the
single-court technology is proven.

**What this pass adds.** A genuinely new cross-cultural signal, and the strongest one in this
packet: of the four new monastic traditions researched, **none independently required a
second, filtered court to function** — the khanqah is a single four-iwan courtyard with cells
opening directly onto it; the Coptic compound's real internal division is not an outer/inner
court filter but a **separate fortified keep** (a different mechanism entirely, see
`BREADTH-SWEEP.md` §1.1); Debre Damo and the *shichidō garan* do not use a filtered-court model
at all. Four more independent data points, and the two-court filter shows up in **zero** of them
— which is consistent with (not proof of) the original recommendation that it is a later,
optional elaboration rather than a baseline requirement.

**What this changes later.** Nothing new — still arrives with M1-C as scoped.

**Revisibility.** Easy.

**Proof needed.** Unchanged.

### M5 — The deck: head-commanding chapel first, free-standing chapel arrives with the defended variant

**The choice.** Does the sanctuary/authority focus command the head of the court (raised
platform, broad stair), or stand free in the middle of the void (the Rila reading)?

**Recommendation (unchanged): head-commanding first.** It is the ruled deck; FFT's five raised
platforms already agree (original synthesis §2); M1-B's grand stair is already its access. The
free-standing chapel arrives together with the defended variant, because it IS the fortified-
church composition.

**What this pass adds — one honest complication, not a contradiction.** The khanqah's **qibla
iwan is a head position claimed by direction (facing Mecca), not by height or a raised platform**
(`BREADTH-SWEEP.md` §1.4). This is a genuinely different deck logic from every source in the
original study, and it means the working spec's own REQUIRED invariant — "the head position is
earned... legal access, tactical value, ritual/social meaning, and at least one counterplay" —
is already phrased generally enough to admit it (it does not say "the highest point"), but the
catalog's shorthand "whoever holds the head overlooks the approach" (Site 4 thin brief, "The
deck") describes only the elevation-based version. **This does not argue against building the
head-commanding chapel first** — the RULED seed is a hillside compound where elevation is the
natural head-claiming device, and nothing in the khanqah evidence contradicts that. It does
suggest the working spec's deck language should eventually note that "commanding the head" can be
claimed by direction as well as height, as a documentation clarification, not a build-order
change. Recorded as `PROPOSED — documentation only`, not folded into the working spec's REQUIRED
text by this pass.

Separately, `BREADTH-SWEEP.md` §2.3 offers a **new, additional PROPOSED variant** outside the
M1/M2/M4/M5 set: a secular-occupancy "communal dining/assembly hall as the head position," evidenced
by the kibbutz dining hall functioning as the community's real social/political center with no
church present at all. This is not a change to M5's chapel-first order for the RULED religious
seed — it is a candidate LICENSED variant for secular/collective occupancy states, offered for a
future founder pass, not this one.

**What this changes later.** Nothing to M5 itself. Flags one documentation clarification and one
new candidate variant for a future pass.

**Revisibility.** Easy (the documentation note); the new variant is not yet scoped enough to rate.

**Proof needed.** Unchanged for M5 itself.

## 3. One thing this pass found that does not fit the M1/M2/M4/M5 frame — recorded honestly, not smoothed in

The Japanese Zen *shichidō garan* (`BREADTH-SWEEP.md` §1.3) is not a wrapped-courtyard
institution at all. It is **seven separate, single-purpose buildings** (gate, Buddha hall, dharma
hall, monks' hall, kitchen, bathhouse, lavatory) related by a processional sequence rather than by
a shared arcaded perimeter. This is real, sourced, imaged evidence for a **distinct institutional
chassis** — not a variant of Site 4's `CLOISTER_VOID`/`ARCADE_BAY` grammar, but a different
organizing principle (sequence of discrete halls vs. enclosure around one void). The
2026-07-28 adversarial review keeps it inside the Site-4 host family and requires multiple
chassis: wrapped court, processional campus, cliff/terrace, and distributed house. Founder
authority still owns their build order.
