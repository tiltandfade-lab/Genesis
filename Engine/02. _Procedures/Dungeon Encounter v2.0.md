# III. Alert Level

| Level | State | Effect |
|:------|:------|:-------|
| 0 | Unaware | Normal activity. |
| 1 | Suspicious | Minor repositioning. Enemies cautious. |
| 2 | Searching | +1 creature to future combat. Defensive repositioning. |
| 3 | Mobilized | Boss fortifies or relocates. Reinforcement roll. |

**Increases when:** combat 3+ rounds / loud magic / enemy escapes / alarm triggered / distortion event.
→ Increase Alert by 1 (max 3)

**Alert 3 — Reinforcements:**
[[Dungeon Reinforcements]]
`dice: [[Dungeon Reinforcements#^dungeon-reinforcements]]`

**Resets when:** long rest outside dungeon / dungeon cleared / narrative justification.
