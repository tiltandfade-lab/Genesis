# Meshy source archive

`incoming/` is temporary staging. Adjudicated files are moved here after every intake pass.

- `adjudicated/`: canonically named raw donors already associated with a production job.
- `variants/`: worthwhile alternate source donors.
- `rejected/`: rejected source donors retained as evidence.
- `organic/canonical/`: accepted organic-family sources.
- `organic/variants/`: useful organic alternates.
- `organic/rejected/`: rejected organic sources.
- `connective-parts/geometry-source/`: lightweight geometry-only connective sources worth retaining.
- `ledgers/`: historical source-routing ledgers.

Large Meshy texture wrappers are not automatically archived. If they provide no reusable semantic
material segmentation, preserve the cleaned geometry and proof render, record the disposition in the
batch audit, and delete the wrapper. Runtime assets use Genesis-owned material channels and textures.
