| **d12** | **Topology** | **Structure** |
| :------ | :----------- | :------------ |
| **1** | The Spine | Rooms chain in a single sequence. 1–2 dead-end branches off the main corridor. Tension-forward, easy to pace. |
| **2** | The Branch | A main path forks into 2–3 parallel routes that reconverge before the finale. Players choose their approach. |
| **3** | The Loop | A ring of rooms with one or two cross-passages cutting through the middle. Rewards exploration. |
| **4** | The Figure-8 | Two connected loops sharing a central hub room. Natural pacing with a mid-point pivot. |
| **5** | The Hub | A large central chamber with 3–5 radiating corridors, each leading to a cluster of 2–3 rooms. |
| **6** | The Web | Multiple overlapping loops with cross-connections. High navigational complexity. Best for mystery or heist dungeons. |
| **7** | The Cascade | Rooms descend in tiers. A gatekeeper challenge — lock, guardian, or puzzle — separates each tier from the next. |
| **8** | The Onion | An outer ring of rooms surrounds an inner sanctum. Access to the inner layer must be earned. |
| **9** | The Stronghold | A functional layout — barracks, kitchen, guard post, armoury — with defensible chokepoints between zones. |
| **10** | The Ruin | Asymmetric and partially collapsed. Some routes are blocked, others newly opened by structural failure. |
| **11** | The Convergence | 2–3 distinct entry points funnel independently toward a single shared finale room. |
| **12** | The Labyrinth Fragment | Dense cluster of short corridors and small rooms. Deliberate confusion, multiple false dead-ends. |
