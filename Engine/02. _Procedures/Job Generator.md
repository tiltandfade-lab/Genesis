# The Wayside Tavern Job Board — Procedural Mechanics (d10 tables)

> **Use case:** Generate 6 postings at dusk/dawn, hand players paper strips, run pure sandbox jobs without prewriting.  
> **Guardrail:** Job Board jobs should NOT directly send PCs into core seeds (deep Mere, major cult rites, main obelisk/monolith delves).  
> **Allowed:** edge effects, logistics, civic trouble, minor weirdness, “foreshadow” postings.

---

## Board Refresh Procedure (60–120 seconds)

1) **Set Refresh:** Dusk = more urgent/night-safe jobs. Dawn = more travel/escort/day work.  
2) **Generate 6 postings:**
   - 2 **Work** (logistics / delivery / repairs)
   - 2 **Civic** (disputes / petty crime / harassment / missing persons)
   - 1 **Wild** (outer-ring hazard / creature / terrain problem)
   - 1 **Weird or Foreshadow** (odd but *not* core; or “too big” posting that stays pinned)
3) For each posting, roll:
   - **Category** (d10) → sets vibe + typical risk
   - **Task** (d10)
   - **Place** (d10)
   - **Deadline** (d10)
   - **Complication** (d10)
   - **Patron** (d10)
   - **Job Length** (d10)
   - **Pay** (by length table)
   - **Add-On Bounty** (optional, d10)
4) Write it as a **one-sentence posting** + pay:
   - “Need **[TASK]** at/near **[PLACE]** **[DEADLINE]**. Problem: **[COMPLICATION]**. Ask for **[PATRON]**. Pay: **[PAY]**. Add-on: **[ADD-ON]**.”

## Bundles (RPG-style Contract Packs)

### How to Build a Pack (10 seconds)
Pick/roll:
- **Anchor Job:** Generate normally (usually Standard or Heavy)
- **Bonus Objective:** Roll Add-On Bounty OR roll Task + Place (Quick)
- **Wildcard Twist:** Roll Complication OR Consequence Tag (apply mid-run)

> **Pack payout:** Anchor pay + bonus pay (add-ons stack).  
> **Pack feel:** One outing, multiple wins, more “adventure density.”

## GM Guardrails (keep it sane)
- Don’t generate more than **one** Heavy job per refresh.
- Any Weird result that smells like a core seed becomes **Foreshadow** instead.
- Default DCs: **12** common, **14** risky, **16** serious.
- Use MM stat blocks as written; reskin freely (stirges, giant frogs, bandits, scouts).
