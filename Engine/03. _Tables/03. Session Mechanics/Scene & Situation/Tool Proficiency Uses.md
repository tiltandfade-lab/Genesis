#tool-proficiency-uses
> **What a tool proficiency actually lets you DO — an anti-drift adjudication lookup.** Today whether a tool applies, and at what difficulty, is pure DM fiat. This is a **reference, not a roll table** (no dice — the compiler skips it; it is served to the DM via the digest). When a player with a tool proficiency wants to *do* something, the DM finds the row and uses the listed ability + DC instead of inventing one, so the same tool resolves the same way across a long campaign. Anchored to the **standard DC ladder** (below). Example uses are Genesis-native, IP-clean (the per-tool task structure is mined from XGtE's Tools chapter; tasks authored fresh 2026-06-28). Extend freely — the pattern is `Tool · keys an ability · the task · DC`.

**The DC ladder (the consistency spine — see the DMG anti-drift "DC ladder" scaffold):**
Very Easy **5** · Easy **10** · Medium **15** · Hard **20** · Very Hard **25** · Nearly Impossible **30**.
*Proficiency with the right tool typically adds the proficiency bonus; lacking the tool can make a task Hard-or-impossible regardless of skill.*
