# Slice-1 Gate Matrix (P12.9, authored for the exact slice Q12-B would name)

## 1. The exact slice (never "the redesign")

**Stage 1 of `docs/FEATURE-PRIORITIZATION.md` §3 — the connected spine in one retained clay
room: Clay Passes C1A → C1B → C1C → C1D first, then C1E → C1F → C1G hardening; the six
Stage-1 features (rules & dice kernel · spatial truth kernel · BattleMat + EngagementLens ·
DM seat + turn digest · save & recovery · workbench floor).** Felt milestone: Adam plays the
C1D room fight — real rules, real board, real DM — saves, quits, reloads, and it is all
still true. Explicitly **not** in the slice: C1H–C1K (Stage-2 visual proof), every C2+ pass,
travel/town/separation/secrets modules, faction simulation, and all Stage-2+ features.

**Erratum note (label gloss, no semantic conflict):** P12.10's step-1 parenthetical glosses
C1A→C1D as "canonical mechanics → BattleMat + EngagementLens → seat/fallback →
persistence/recovery." The ladder — the authority on pass ids — defines C1C = object/hazard/
custody and C1D = the battle spine, with save/recovery at **C1F** and the DM seat at **C1G**.
The slice therefore names C1A→C1G so the felt milestone (save, quit, reload; real DM) is
actually reachable. The four systems in the gloss are all in the slice; only the letter
mapping was compressed. Recorded here per the reopen law's spirit; nothing reopens — the
ladder's definitions govern.

## 2. Gate typing law (P12.9, accepted at W12 §20.6 item 9)

- **BLOCK** — truth, recovery, legality, privacy-leak gates. A red here stops the pass from
  being declared arrived. Truth is never warned away.
- **WARN** — polish, beauty, perf-*target* gates, until their named milestone. A warn is
  recorded in the pass record, never hidden — and polish can never block truth work.
- Arrival on every pass additionally follows the FEATURE-PRIORITIZATION §0 arrival law
  (fresh deterministic green · personal re-gate · human eyes on actual output · ledger flip
  with evidence).

## 6. Budgets against the no-cash ceiling (GEN-LAW-9, ~$200/month)

The slice's marginal cost is **$0 in services**: local Mac compute; jsdom harnesses and the
existing GitHub CI (free tier); existing Claude/Codex subscriptions already inside the
operating baseline; no new paid dependency, model, or service. Stage-0 recovery artifacts
consume local disk (~10 GB) plus existing Google Drive storage. Nothing in the slice
approaches the ceiling.

## 7. Reopen trigger (the P12.12 line)

Any contradiction discovered between build reality and a closed wave's ruling **reopens that
wave explicitly** — a named contradiction in a dated section of the owning record — before
any code lands on the contradicting subject. Never a silent workaround, never a quiet
amendment.

## 8. Migration rider

The slice introduces save schema v1; from that moment the migration registry is live and the
first old-save fixture is retained (P12.3) — every later schema change carries its expansion
fixture. Migrations always BLOCK on their fixture.
